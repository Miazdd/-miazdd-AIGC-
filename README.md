2. 打开你的AI Agent平台（OpenClaw/Coze/Dify）

4. 加载模型，即可直接启动漫剧全自动化流程

## 📖 使用教程
1. 基础配置：选择对应模型 Seedance / MiniMax H3
2. 输入需求：填写短剧题材、主角人设、故事大纲
3. 一键执行：自动输出完整剧本、人物定妆描述、分镜、封面提示词
4. 支持迭代修改，可反复调整人设与剧情
