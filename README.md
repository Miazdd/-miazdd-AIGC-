## 📝 使用方法
1. 下载本项目 miazdd.zip
2. 在Flova/WorkBuddy平台导入Skill包
3. 输入漫剧需求，一键启动流水线创作

Miazdd 是一套把「写爽剧 → 锁资产 → 做分镜 → 跑 Flova 制作」串成工业化流程的技能，为 Miazdd 原创整合的方法论与纪律体系。它把三套创作体系压成一个可调用的工作流：

01 · 短剧爆款写作方法论：怎么写出符合下沉付费市场的爆款短剧剧本。
02 · AIGC 漫剧工业管线纪律：怎么用工业纪律做视觉与分镜。
03 · Flova 漫剧项目操作纪律：怎么把上面两套落到 Flova 项目运行里。
它的本质是「方法论 + 纪律」层，不实际生成图或视频——真生成交给 Flova（或外部视频模型）。它解决的是「大模型瞎写分镜投喂词、做一半发现画幅不对、人设中途崩、分镜里人凭空消失」这类返工与漂移问题。

二、为什么做这个技能（来源）
由三份学习成果整合而来，对外统一以「Miazdd 原创」口径呈现：

剧本大全深度学习：从桌面约 456 份短剧语料（约 1GB）全量提取、分类、并行精读后提炼的爆款写作方法论。
AIGC 漫剧工业管线：从一份 AIGC 全流程创作规则库提炼的视觉 / 分镜工业纪律（四前置锁、Asset-First、FACS、12 节拍、镜头空间、七段式、禁令三改法等）。
Flova 漫剧创作规范补丁：把上述两套落到 Flova 项目运行的八条操作纪律（立项停点、资产评审、语气位、首镜单主体、三步复验、声音电平、跑前自检）。
三者叠加 = 从「写什么」到「怎么拍」到「怎么管项目」的完整闭环。

五、三份知识模块详解
5.1 · 01 剧本方法论（写剧本）
硬指标：整本 80–100 集；每集 1–1.5 分钟；每集 500–700 字；总时长约 100 分钟。投稿去向抖音 / 快手 / 小程序（九州、点众、容量、番茄）。
选题四步：定男频/女频对标大类 → 模仿节奏（前三集拉满）→ 模仿框架（提主题非抄细节）→ 模仿台词。创新 = 在已验证题材上做 1+n 类型重组。
人设铁律：主角必须正面；用「表面…实则…」反差结构；反派坏得彻底、台词粗俗带身份；先写人物小传再写大纲。
结构节奏：开篇即矛盾、前三集情绪拉满；前 20 集集集冲突、前 30 集集集打脸。
爽点/钩子：爽感来源、情绪铁律、期待感三法、视角信息差、反转/错觉、每集结尾钩子、付费卡点常设 10/30/60/80 集、冲突强度公式（施力点×受力点）。
功能零件 + 避坑清单 + 三十六情节模式 Top10 + 十一种断集方式。
单集标准四拍：压 → 装 → 打 → 爆 → 发 → 拉。
长篇结构分段：开头立梗(10%)→铺垫绑定(10–15%)→反复虐拉扯(50–60%)→反转高潮(15–20%)→收线(10%)。
七类可复用范本骨架（古言穿越打脸、现言重生复仇、小人物逆袭、悬疑灵异单元、男频扮猪吃虎、男频重生神豪、古言女强甜宠权谋）。
合规 5 红线：擦边低俗 / 拜金躺平导向 / 历史虚无低级红 / 格调低下 / 程序违规（缺许可证与备案号）。
两套可直接套的模板：人物小传模板、单集剧本格式模板（含 △动作符、OS/Vo、闪回标注、集末钩子、【付费卡点】）。
5.2 · 02 AIGC 工业管线（资产与分镜）
四前置锁（动笔前必须锁，未指定=停下问，禁止默认）：A 视觉方向 / B 画幅 / C 交付形态 / D 段缝衔接。
四条默认铁律：只出词不出图（若仅做词）、单镜头时长按剧情倒推、台词必须视频内出、禁真人照片 ≠ 禁写实画风。
Asset-First 六阶段 P0~P5：立项→门控编剧→资产锁定→文武双模分镜→提示词封装→质检看板。
五阶门控编剧：立意→三幕→节拍→实体清单→剧本页，每阶有闸。
情绪与表演：12 节拍情绪曲线（第 9 节拍反杀峰值约 9.5，前段须有压抑波谷）；FACS 微表情（真假笑=AU6+AU12 同时）；文戏六阶段递进。
台词与声画：七维诊断 + 语速 3.5~5 字/秒 + 语气位格式 台词：【角色（语气）："…"】；OS/VO 声画分离红线。
动作武学：11 环杀招动力链、防守三态、R1 写实/R2 商业高燃/R3 玄幻 三档、去水五律。
镜头与空间：镜头规格 15 铁律（首镜单主体、禁「X 与 Y 同框」并列）；站位四要素（位置/依托物/朝向/姿态）+ 摆位必入画；画幅与资产解耦（资产统一 16:9 出）。
提示词封装：七段式【画幅风格→场景资产→核心人物→站位声明→时间轴分镜→音效→强制禁止项】；选 H3 时转六段式；禁令三改法（禁「不要 XX」，改词根替换+正向替代）。
台账与质检：CHR/AUD/PRP/SCN/Uxx 五类资产 ID 台账；P0~P2 门禁；声音三层电平（对白 0dB > SFX -6dB > BGM -14dB）；改动三步复验；六大美学预设（诗意/纪实/港派/赛博/水墨/国漫）。
5.3 · 03 Flova 操作纪律（项目运行）
八条纪律，各自嵌进 Flova 生命周期停点：①四前置锁（立项停点）②Asset-First（资产评审点）③语气位（台词评审点）④首镜单主体+摆位必入画（分镜硬指标）⑤禁令三改法（约束措辞）⑥12 节拍曲线（结构评审点）⑦改动三步复验（修改纪律）⑧声音三层电平（导出前混音）。
跑前自检清单（每次发 run 前过 8 项）：四前置锁确认 / 资产锁定 / 语气位 / 首镜单主体 / 禁止项三改 / 情绪曲线 / 三步复验 / 声音电平。任一项标红就停在对应环节等用户确认。
停点映射：立项→资产→结构→分镜→修改→导出前，逐环有闸。
中文指令片段速查：八句可直接抄进创作消息的确认语与指令。
六、三步工作流
第一步 · 写剧本（读 01）
先锁商品定位：题材（男频/女频）、集数体量、付费卡点位置。用单集四拍 + 十一断集做钩子，用人物小传与单集格式模板落稿。写完自查合规 5 红线。

第二步 · 资产与分镜（读 02）
过四前置锁 → Asset-First 先出角色 4 View + 场景三件套 + 道具图并建 ID 台账，再进分镜。分镜守 12 节拍曲线、FACS、镜头 15 铁律、语气位格式；提示词七段式封装；禁止项走三改法。

第三步 · Flova 制作（读 03）
把第二步纪律转成操作闸：立项停点→资产评审点→结构评审点→分镜评审点→导出前。每次发 run 前过跑前自检 8 项，标红即停。直接用 03 末尾的中文指令片段写创作消息。

七、最该记住的核心纪律（速查）
四前置锁没确认 → 不建项。
资产没锁定且用户没确认 → 不放行分镜。
对白没带语气位、分镜首镜非单主体、摆位有人没入画 → 打回。
禁止项出现「不要 XX」词根 → 改走三改法。
情绪曲线第 9 节拍无反杀峰值 → 重排节拍。
修改未做三步复验 → 不发。
导出前混音对白被掩 → 打回。
单集四拍口诀：压 → 装 → 打 → 爆 → 发 → 拉。
合规 5 红线是硬下限：极致情绪写法必须带真实立意，不能纯靠刺激付费。
